## Context

### Original Request
Add complete JS/TS plugin support to polyplug (Epic 10), following the same adapter crate pattern as `polyplug-lua` and `polyplug-python`. All three JS sub-runtimes (node, bun, deno) scaffolded; node fully implemented; bun/deno stubbed with clear `RuntimeNotImplemented` errors.

### Architecture Decision: Subprocess Bridge (not embedded engine)
The PRD (line 772) explicitly specifies the Node loading mechanism: "polyplug-js loads it via `require()` called through the Node subprocess bridge." The JS/TS plugin model is:
- **NOT** an embedded JS engine (unlike Lua/Python)
- **NOT** in-process dlopen of the .node file directly
- **IS** a subprocess bridge: Rust spawns a Node.js process, passes the registrar pointer + IPC socket path via environment variables, and the Node process loads the `.node` N-API addon, calls `polyplug_init(registrar_ptr)` via the addon, which registers vtable function pointers. The vtable functions themselves are compiled C ABI functions inside the `.node` shared library — they run in the **Rust host process address space** (the .node file is dlopen'd by the Node subprocess bridge runner into the host process).

Wait — this is still architecturally problematic: if Node runs in a subprocess, vtable function pointers point into a different address space. The PRD must mean something different.

**Revised Architecture Decision (final)**:
Re-reading the PRD carefully: `ts-node`/`js-node` generates a `.node` file — a compiled N-API shared library. `polyplug-js` loads this file in-process using `libloading` (identical to how the native loader works). The "Node subprocess bridge" phrase refers to the **developer workflow** (using `ts-node` to transpile TS to the `.node` artifact), NOT a runtime subprocess. At load time, `JsLoader` simply calls `libloading::Library::new(path)` and resolves `polyplug_init` — the same as `NativeBundleLoader`. The N-API stability guarantee means the `.node` file's `polyplug_init` symbol is pure C ABI, no Node runtime needed.

For `ts-bun`/`js-bun` and `ts-deno`/`js-deno`: the generated plugin IS a `.js`/`.ts` source file that uses `bun:ffi` or `Deno.dlopen` to call BACK into `polyplug.so` (the host runtime). This is the reverse direction — the plugin file is NOT loaded by Rust, it IS the thing that calls Rust. This means for bun/deno, the app developer spawns bun/deno and the plugin runs there, calling into the polyplug runtime via FFI. This is a fundamentally different execution model and is rightly stubbed for Epic 10.

**Final Architecture for Epic 10**:
- `ts-node`/`js-node`: `JsLoader` dlopen's the `.node` file via `libloading`, resolves `polyplug_init` symbol (C ABI), calls it — identical to `NativeBundleLoader`. The `.node` file's `polyplug_init` is a pure C function (generated by `polyplugc --lang ts-node`). N-API machinery is only used for the TS→compiled bridge in the plugin developer's build step.
- `ts-bun`/`js-bun`: Stub. Returns `RuntimeNotImplemented`. (Future: Rust spawns `bun` with the JS file, waits for vtable registration via IPC/shared memory.)
- `ts-deno`/`js-deno`: Stub. Returns `RuntimeNotImplemented`. (Future: same as bun.)

**BundleLoader trait**: Since each `JsLoader` instance handles exactly one runtime name, the plan adds `fn runtime_names(&self) -> Vec<String>` as a **default method** to the `BundleLoader` trait, returning `vec![self.runtime_name().to_owned()]`. No existing adapter crates need patching. `RuntimeBuilder::build()` iterates `runtime_names()` in the loader registration loop. `JsLoader` inherits the default (one instance per runtime variant).

     ```rust
     //! Node sub-loader for ts-node/js-node bundles.
     //!
     //! Loads `.node` shared libraries in-process via `libloading`.
     //! The `.node` file must export:
     //!   - `polyplug_abi_version: extern "C" fn() -> u32`
     //!   - `polyplug_init: extern "C" fn(*mut PluginRegistrar) -> AbiError`
     //!
     //! No Node.js subprocess is spawned. The `.node` file is a standard C ABI
     //! shared library — the `.node` extension is a Node.js naming convention only.

     use std::path::Path;
     use std::sync::Mutex;
     use std::sync::OnceLock;

     use polyplug::abi::ABI_OK;
     use polyplug::abi::AbiError;
     use polyplug::abi::POLYPLUG_ABI_VERSION;
     use polyplug::abi::PluginRegistrar;
     use polyplug::error::LoaderError;
     use polyplug::error::PolyplugError;

     use crate::config::NodeConfig;

     // ─── Never-drop library storage ───────────────────────────────────────────
     //
     // All loaded libraries are moved here immediately after symbol resolution.
     // They are NEVER dropped — dropping a Library calls dlclose(), which would
     // unmap the plugin's code pages while vtable function pointers are still live.
     static LOADED_LIBRARIES: OnceLock<Mutex<Vec<libloading::Library>>> = OnceLock::new();

     fn loaded_libraries() -> &'static Mutex<Vec<libloading::Library>> {
         LOADED_LIBRARIES.get_or_init(|| Mutex::new(Vec::new()))
     }

     /// Load a ts-node/js-node `.node` bundle by dlopening it in-process.
     ///
     /// Steps:
     /// 1. Check `path` exists and is a file.
     /// 2. `libloading::Library::new(path)` (RTLD_NOW | RTLD_LOCAL).
     /// 3. Resolve `polyplug_abi_version`, check against `POLYPLUG_ABI_VERSION`.
     /// 4. Resolve `polyplug_init`, copy fn pointer out of Symbol borrow.
     /// 5. Move library into `LOADED_LIBRARIES` (never-drop invariant).
     /// 6. Build `PluginRegistrar` with `registrar_callback` and call init.
     /// 7. On init failure: library is already stored; return `JsInitRaisedError`.
     pub(crate) fn load(
         path: &Path,
         registrar: &mut PluginRegistrar,
         _config: &NodeConfig,
     ) -> Result<(), PolyplugError> {
         let path_str: String = path.to_string_lossy().into_owned();

         // SAFETY: The path points to a compiled .node bundle with C ABI.
         // libloading handles platform-specific loading.
         // If the file is not a valid shared library, libloading returns Err.
         let library: libloading::Library = unsafe {
             libloading::Library::new(path).map_err(|e: libloading::Error| {
                 PolyplugError::Loader(LoaderError::LoadFailed {
                     path: path_str.clone(),
                     source: e,
                 })
             })?
         };

         // Step 1: Check ABI version sentinel.
         // SAFETY: polyplug_abi_version is a C function with signature `extern "C" fn() -> u32`.
         // libloading resolves the symbol; if absent, get() returns Err.
         // The symbol is dropped after use to release its borrow on `library`.
         let found_version: u32 = {
             let sym: libloading::Symbol<'_, unsafe extern "C" fn() -> u32> = unsafe {
                 library
                     .get(b"polyplug_abi_version\0")
                     .map_err(|_| PolyplugError::Loader(LoaderError::MissingSymbol {
                         bundle: path_str.clone(),
                         symbol: "polyplug_abi_version".to_owned(),
                     }))?
             };
             // SAFETY: symbol was just resolved and is valid. No side effects.
             let v: u32 = unsafe { sym() };
             v
         };
         // sym dropped here, releasing borrow on library.
         if found_version != POLYPLUG_ABI_VERSION {
             return Err(PolyplugError::Loader(LoaderError::AbiVersionMismatch {
                 bundle: path_str.clone(),
                 expected: POLYPLUG_ABI_VERSION,
                 found: found_version,
             }));
         }

         // Step 2: Resolve init symbol and copy fn pointer out of Symbol borrow.
         // SAFETY: polyplug_init is guaranteed by the plugin build process to have
         // signature: extern "C" fn(*mut PluginRegistrar) -> AbiError.
         // Symbol<F> derefs to F (a fn pointer, which is Copy).
         // The pointer remains valid as long as the library is alive.
         // Library is moved into LOADED_LIBRARIES immediately after this block.
         let init_fn_ptr: unsafe extern "C" fn(*mut PluginRegistrar) -> AbiError = {
             let sym: libloading::Symbol<
                 '_,
                 unsafe extern "C" fn(*mut PluginRegistrar) -> AbiError,
             > = unsafe {
                 library
                     .get(b"polyplug_init\0")
                     .map_err(|_| PolyplugError::Loader(LoaderError::MissingSymbol {
                         bundle: path_str.clone(),
                         symbol: "polyplug_init".to_owned(),
                     }))?
             };
             // SAFETY: Deref of Symbol<F> where F is a fn pointer type (Copy).
             // This copies the function address without cloning Library.
             *sym
         };
         // sym dropped here.

         // Step 3: Move library into LOADED_LIBRARIES BEFORE calling init.
         // SAFETY: library is a successfully loaded shared library.
         // Moving it into LOADED_LIBRARIES transfers ownership.
         // It will never be dropped — the never-unload invariant applies.
         {
             let mut guard: std::sync::MutexGuard<'_, Vec<libloading::Library>> =
                 loaded_libraries()
                     .lock()
                     .unwrap_or_else(|e: std::sync::PoisonError<_>| e.into_inner());
             guard.push(library);
         }

         // Step 4: Call polyplug_init.
         // SAFETY: init_fn_ptr was resolved from the library (now in LOADED_LIBRARIES).
         // registrar is a valid mutable reference for the duration of this call.
         let init_result: AbiError = unsafe { init_fn_ptr(registrar as *mut PluginRegistrar) };

         if init_result.code != ABI_OK {
             // Library is already in LOADED_LIBRARIES — never-unload invariant.
             // SAFETY: init_result.message.ptr is either null or a static string
             // in the plugin binary (which is never unloaded).
             let error_msg: String = if init_result.message.ptr.is_null() {
                 format!("init returned error code {}", init_result.code)
             } else {
                 // SAFETY: ptr is non-null and points to valid UTF-8 bytes for len bytes.
                 let bytes: &[u8] = unsafe {
                     core::slice::from_raw_parts(
                         init_result.message.ptr,
                         init_result.message.len,
                     )
                 };
                 String::from_utf8_lossy(bytes).into_owned()
             };
             return Err(PolyplugError::Loader(LoaderError::JsInitRaisedError {
                 bundle: path_str,
                 message: error_msg,
             }));
         }

         Ok(())
     }
     ```
