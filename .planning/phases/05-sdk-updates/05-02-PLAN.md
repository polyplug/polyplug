## polyplug_abi RuntimeConfig Layout (24 bytes)

From crates/polyplug_abi/src/runtime/runtime_config.rs:
```rust
#[repr(C)]
pub struct RuntimeConfig {
    pub hot_reload_enabled: bool,      // 1 byte @ offset 0
    pub hot_reload_max_retries: u32,   // 4 bytes @ offset 4
    pub hot_reload_retry_interval_ms: u64, // 8 bytes @ offset 8
    pub hot_reload_abort_on_max_retries: bool, // 1 byte @ offset 16
    pub compatibility: Compatibility,  // 4 bytes @ offset 20
}
// Total: 24 bytes with alignment padding
```

Compatibility enum (#[repr(u32)]):
- Strict = 0
- Relaxed = 1
- Yolo = 2

## Python polyplug_abi.abi RuntimeConfig

From sdks/python/polyplug_abi/polyplug_abi/abi.py lines 234-249:
```python
class RuntimeConfig(ctypes.Structure):
    _fields_ = [
        ("plugin_dirs", ctypes.c_void_p),
        ("plugin_dir_count", ctypes.c_size_t),
        ("compatibility", ctypes.c_uint32),
        ("extensions", ctypes.c_void_p),
        ("extension_count", ctypes.c_size_t),
    ]
```

NOTE: This is the OLD RuntimeConfig layout (40 bytes) for bundle creation, NOT the hot-reload RuntimeConfig (24 bytes). The hot-reload RuntimeConfig should be named HotReloadConfigC or similar in Python.
