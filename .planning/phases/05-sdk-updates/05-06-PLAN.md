## Instance Model from Phase 3

From crates/polyplug_abi/src/guest/guest_contract_interface.rs:
```rust
pub struct GuestContractInterface {
    pub contract_id: GuestContractId,
    pub contract_version: Version,
    pub dispatch_type: DispatchType,
    pub create_instance: unsafe extern "C" fn(
        rt_ctx: *mut c_void,
        args: *const (),
    ) -> GuestContractInstance,
    pub destroy_instance: unsafe extern "C" fn(
        rt_ctx: *mut c_void,
        instance: GuestContractInstance,
    ),
    pub dispatch: DispatchMechanisms,
}
```

## Instance Wrapper Requirements

Generated wrappers MUST:
1. Call create_instance in constructor/factory method
2. Store the GuestContractInstance handle
3. Pass instance as first argument to dispatch calls
4. Call destroy_instance in destructor/dispose method
