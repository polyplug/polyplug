# PLAN: Add Warning Callback for Instance Leak Detection

**Objective:** Add Arc::strong_count check after Preparing callback to emit warning if host may not have destroyed all instances.

**Purpose:** Inform host of potential undefined behavior without blocking reload. Host responsibility model: warning is informational, not blocking.

**Output:** Runtime.reload_bundle with warning check, updated documentation.

<action>
Insert warning check AFTER Preparing callback fires, BEFORE loader.reload() call.

In `reload_bundle()` function, after the Preparing callback block (around line 161), add:

```rust
// ─── Warning Check: Informational only, not blocking ─────────────────────────────
// Check Arc::strong_count after Preparing callback returned.
// If > 1, host may not have destroyed all instances - emit UB warning.
let slot_indices: Vec<u32> = self.registry.find_slots_by_bundle(bundle_id);
for slot_idx in &slot_indices {
    if let Some(arc) = self.registry.get_interface_arc(*slot_idx) {
        if Arc::strong_count(&arc) > 1 {
            self.emit_warning(&format!(
                "Potential UB: Arc refs still exist for bundle '{}' after Preparing callback. \
                 Host may not have destroyed all instances. Proceeding with reload anyway.",
                manifest.name
            ));
            // Only emit once per bundle, not per slot
            break;
        }
    }
}
```

Note: Import `Arc` if not already imported in reload.rs: `use std::sync::Arc;`
</action>
