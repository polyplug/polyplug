# Plan 06-13: Update Test Files to Use New Type Names

## Objective

Update all test files that use removed type aliases (`PluginInterface`, `HostVTable`, `PluginDispatch`) to use the new names (`GuestContractInterface`, `RuntimeAbi`, `GuestContractId`, etc.).

## Background

Multiple test files still import and use removed type aliases:
- `PluginInterface` → `GuestContractInterface`
- `HostVTable` → `RuntimeAbi`
- `PluginDispatch` → removed (use dispatch union)
- `BundleId` (now a newtype, not u64)
- `HostContractId` (now a newtype, not u64)
- `NativeDispatch` now has `function_count` field
- `AbiError.code` is `AbiErrorCode`, not `u32`

## Tasks

### Task 1: Identify All Affected Test Files

```bash
grep -r "PluginInterface\|HostVTable\|PluginDispatch" crates/*/tests/
```

### Task 2: Fix Type Imports

For each file found:

| Old Import | New Import |
|------------|------------|
| `polyplug_abi::PluginInterface` | `polyplug_abi::GuestContractInterface` |
| `polyplug_abi::HostVTable` | `polyplug_abi::RuntimeAbi` |
| `polyplug_abi::PluginDispatch` | (use DispatchMechanisms union) |

### Task 3: Fix NativeDispatch Construction

Add `function_count` field:
```rust
NativeDispatch {
    function_count: N,  // Add this
    functions: &ARRAY,
}
```

### Task 4: Fix AbiError Construction

Change:
```rust
AbiError { code: 1_u32, message }
```

To:
```rust
AbiError { code: AbiErrorCode::Generic, message }
```

### Task 5: Fix ID Type Conversions

For `BundleId`, `GuestContractId`, `HostContractId`:
```rust
// Old:
let id: u64 = 0x1234;

// New:
use polyplug_utils::BundleId;
let id = BundleId::from(0x1234_u64);
```

### Task 6: Run Tests

```bash
cargo test --workspace
```
