
NEW: HostInterface method calls

Per D-18-33: Update Rust generator to produce code that uses HostInterface methods.

Changes to host caller generation:
```rust
// OLD pattern (direct FFI call):
// let rt: *mut OpaqueRuntime = polyplug_runtime_create();
// polyplug_runtime_load_bundle(rt, path_ptr, path_len);

// NEW pattern (HostInterface method call):
// let host: *const HostInterface = polyplug_runtime_create();
// unsafe { (host.as_ref().unwrap().load_bundle)(host, path_ptr, path_len) };
```

Key updates:
1. Runtime handle type: OpaqueRuntime* -> HostInterface*
2. Method calls: Use HostInterface field dereference
3. Self-passing: Pass host pointer as first argument to each method
4. Error handling: Use HostInterface.get_last_error field

Update generate_host_callers or equivalent function:
- Change handle type from `*mut OpaqueRuntime` to `*const HostInterface`
- Generate method calls through HostInterface fields
- Generate helper for get_last_error through HostInterface

Example generated code pattern:
```rust
pub fn load_bundle(host: *const HostInterface, path: &Path) -> Result<(), RuntimeError> {
    let path_bytes = path.to_str().unwrap().as_bytes();
    let result = unsafe {
        let iface = host.as_ref().ok_or(RuntimeError::NullHost)?;
        (iface.load_bundle)(host, path_bytes.as_ptr(), path_bytes.len())
    };
    if result.code != 0 {
        return Err(get_last_error(host));
    }
    Ok(())
}
```
