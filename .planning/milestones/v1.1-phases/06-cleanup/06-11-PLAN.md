# Plan 06-11: Export VmDispatch from polyplug_abi and Regenerate

## Objective

Add `VmDispatch` to the public exports of `polyplug_abi` and regenerate all affected code.

## Background

The Rust generator imports `VmDispatch` from `polyplug_abi`:
```rust
out.push_str("use polyplug_abi::VmDispatch;\n");
```

But `VmDispatch` is not exported from the crate root. It's only available as `polyplug_abi::dispatch::VmDispatch`.

## Tasks

### Task 1: Export VmDispatch from polyplug_abi

**File:** `crates/polyplug_abi/src/lib.rs`
**Line:** 28

Change:
```rust
pub use dispatch::{DispatchType, DispatchMechanisms, NativeDispatch};
```

To:
```rust
pub use dispatch::{DispatchType, DispatchMechanisms, NativeDispatch, VmDispatch};
```

### Task 2: Verify Export Works

Run:
```bash
cargo build -p polyplug_abi
```

### Task 3: Regenerate All Rust Host Code

Run:
```bash
cargo run -p polyplugc -- generate --api examples/api.toml --lang rust --out examples/hosts/rust/src/generated
```

### Task 4: Build Workspace

Run:
```bash
cargo build --workspace
```
