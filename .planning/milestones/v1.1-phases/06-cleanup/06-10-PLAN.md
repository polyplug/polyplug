# Plan 06-10: Fix Rust Generator Host Interface Factory Issues

## Objective

Fix critical bugs in `crates/polyplugc/src/generators/rust.rs` host interface factory generation that prevent compilation of generated code.

## Background

The VERIFICATION.md identified 7 specific issues in the Rust generator that cause build failures:
1. Function names use `_vtable` suffix instead of `_interface`
2. Missing `function_count` field in NativeDispatch
3. Missing imports (AbiErrorCode, abi_error_ok, string_view_from_static)
4. Raw u64 instead of HostContractId for contract_id
5. Unnecessary `as u32` cast for AbiErrorCode

## Tasks

### Task 1: Fix Function Names

**File:** `crates/polyplugc/src/generators/rust.rs`
**Lines:** 1888-1894

Change:
```rust
let factory_name: String = format!(
    "create_{}_vtable",
    contract.name.replace('.', "_").to_lowercase()
);
let factory_vm_name: String = format!(
    "create_{}_vtable_vm",
    contract.name.replace('.', "_").to_lowercase()
);
```

To:
```rust
let factory_name: String = format!(
    "create_{}_interface",
    contract.name.replace('.', "_").to_lowercase()
);
let factory_vm_name: String = format!(
    "create_{}_interface_vm",
    contract.name.replace('.', "_").to_lowercase()
);
```

### Task 2: Add Missing function_count Field

**File:** `crates/polyplugc/src/generators/rust.rs`
**Lines:** 2006-2008

Change:
```rust
out.push_str("            native: NativeDispatch {\n");
out.push_str("                functions: FUNCTIONS.as_ptr() as *const *const (),\n");
out.push_str("            },\n");
```

To:
```rust
out.push_str("            native: NativeDispatch {\n");
out.push_str(&format!("                function_count: {fn_count}_u32,\n"));
out.push_str("                functions: FUNCTIONS.as_ptr() as *const *const (),\n");
out.push_str("            },\n");
```

### Task 3: Add Missing Imports

**File:** `crates/polyplugc/src/generators/rust.rs`
**Lines:** 1864-1872

Add after existing imports:
```rust
out.push_str("use polyplug_abi::AbiErrorCode;\n");
out.push_str("use polyplug_abi::abi_error_ok;\n");
out.push_str("use polyplug_abi::string_view_from_static;\n");
```

### Task 4: Fix HostContractId Usage

**File:** `crates/polyplugc/src/generators/rust.rs`
**Lines:** 2082, 2120 (and VM equivalent)

Add import:
```rust
out.push_str("use polyplug_abi::HostContractId;\n");
```

Change:
```rust
out.push_str(&format!("        contract_id: 0x{contract_id:016X}_u64,\n"));
```

To:
```rust
out.push_str(&format!("        contract_id: HostContractId::from(0x{contract_id:016X}_u64),\n"));
```

### Task 5: Remove Unnecessary u32 Cast

**File:** `crates/polyplugc/src/generators/rust.rs`
**Line:** 2169

Change:
```rust
out.push_str("                code: AbiErrorCode::Panic as u32,\n");
```

To:
```rust
out.push_str("                code: AbiErrorCode::Panic,\n");
```
