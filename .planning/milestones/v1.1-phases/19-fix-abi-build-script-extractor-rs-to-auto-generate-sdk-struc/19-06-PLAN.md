<objective>
Fix two gaps blocking Phase 19 completion: (1) embed helper method source inline in generate.rs as const strings so they survive across rebuilds, and (2) fix C++ handle.hpp to use only the index field for GuestContractHandle comparison.

Output: All 4 SDK abi.* files contain helper methods after clean rebuild; C++ handle.hpp compiles correctly.
