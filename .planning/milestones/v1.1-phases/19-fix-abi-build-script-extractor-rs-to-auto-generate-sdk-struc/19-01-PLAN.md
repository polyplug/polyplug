<objective>
Rewrite the build script extractor to walk the polyplug_abi module tree recursively and auto-discover all ABI types, removing all hardcoded whitelists.

Purpose: The current extractor only parses `src/lib.rs` (the barrel file) and uses stale whitelists that reference types that no longer exist. The ABI types have been modularized into 7+ sub-modules with 35+ source files. The extractor must walk the entire tree to discover all types.

Output: A working build script that discovers all #[repr(C)] types and POLYPLUG_ constants, with zero whitelists, and generates (placeholder-quality) SDK files.
</objective>
