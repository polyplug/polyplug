# Milestone v1.1: Architecture Refactor

**Status:** ✅ SHIPPED 2026-04-17
**Phases:** 1-19
**Total Plans:** 95+

## Overview

Major architecture refactor of polyplug runtime:
- Consolidated all FFI types to polyplug_abi crate
- Replaced legacy vtable naming with interface terminology
- Implemented instance-based lifecycle model with RAII wrappers
- Added callback-based hot-reload with safety contract
- Auto-generated SDK bindings for 5 languages via build script

## Milestone Summary

**Key Decisions:**
- Use polyplug_abi as single source of truth for FFI types
- Instance-based lifecycle replaces PluginGuard
- Callback-based hot-reload with explicit destroy contract
- Auto-generated SDK bindings via build script (no hand-written FFI)

**Issues Resolved:**
- vtable→interface naming consistency across all SDKs
- RuntimeConfigC→RuntimeConfig naming alignment
- PluginGuard removal from all SDKs
- Type safety via typed handles (RuntimeContext, VmLoaderData)

**Technical Debt:**
- Some legacy test fixtures still need updates
- Documentation could be more comprehensive
