# SDK Naming Consistency Fix

## Problem

Python and Lua SDK `abi.py`/`abi.lua` files have:
1. **Wrong type names**: `PluginInterface` → should be `GuestContractInterface`
2. **Wrong type names**: `HostVTable` → should be `HostInterface`  
3. **Wrong struct fields**: Missing `create_instance`/`destroy_instance`, has non-existent `rt_ctx`/`function_count`
4. **Size mismatch**: Would cause FFI corruption

C++ SDK has backwards-compat alias `using HostVTable = RuntimeAbi;` but RuntimeAbi doesn't exist in Rust.

## Scope

| File | Issue | Fix |
|------|-------|-----|
| `sdks/python/polyplug_abi/polyplug_abi/abi.py` | Wrong struct definitions | Regenerate or rewrite |
| `sdks/python/guest/polyplug_guest/__init__.py` | Imports wrong names | Update imports |
| `sdks/lua/abi/polyplug_abi.lua` | Wrong struct definitions | Regenerate or rewrite |
| `sdks/lua/guest/polyplug_guest.lua` | Uses wrong names | Update |
| `sdks/cpp/guest/polyplug/guest.hpp` | Has `using HostVTable = RuntimeAbi` | Remove or update |

## Correct Rust ABI Types

### GuestContractInterface (56 bytes)
```rust
pub struct GuestContractInterface {
    pub contract_id: GuestContractId,      // 8 bytes @ 0
    pub contract_version: Version,         // 12 bytes @ 8  
    pub dispatch_type: DispatchType,       // 4 bytes @ 20
    // padding 4 bytes
    pub create_instance: fn(...),          // 8 bytes @ 24
    pub destroy_instance: fn(...),         // 8 bytes @ 32
    pub dispatch: DispatchMechanisms,      // 16 bytes @ 40
}
```

### HostInterface (88 bytes)
```rust
pub struct HostInterface {
    pub runtime: *mut c_void,              // 8 bytes @ 0
    pub register_plugin: fn(...),          // 8 bytes @ 8
    pub alloc: fn(...),                    // 8 bytes @ 16
    pub free: fn(...),                     // 8 bytes @ 24
    pub find_by_contract: fn(...),         // 8 bytes @ 32
    pub find_all_by_contract: fn(...),     // 8 bytes @ 40
    pub resolve_contract: fn(...),         // 8 bytes @ 48
    pub get_host_contract: fn(...),        // 8 bytes @ 56
    pub get_last_error: fn(...),           // 8 bytes @ 64
    pub list_bundles: fn(...),             // 8 bytes @ 72
    pub get_dependencies: fn(...),         // 8 bytes @ 80
}
```
