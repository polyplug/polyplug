Linux x64 Native Library
=========================

This directory should contain: libpolyplug.so

CI will automatically download this file during build.

Manual download:
  deno run --allow-net --allow-write download-native.ts

Or download from GitHub Releases:
  https://github.com/polyplug/polyplug/releases/download/v{version}/libpolyplug-linux-x64.so
