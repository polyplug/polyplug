# polyplug-loaders-js

JS (QuickJS) loader for polyplug - loads QuickJS plugins.

## Installation

```bash
pip install polyplug-loaders-js
```

## Usage

```python
from polyplug_loaders_js import QuickJSLoader

loader = QuickJSLoader()
# Load plugins written in JavaScript (QuickJS runtime)
```

## Description

This loader handles plugins written in JavaScript, using the QuickJS runtime for lightweight, embeddable JS execution.
