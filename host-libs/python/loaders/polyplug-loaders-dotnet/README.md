# polyplug-loaders-dotnet

.NET loader for polyplug - loads .NET plugins.

## Installation

```bash
pip install polyplug-loaders-dotnet
```

## Usage

```python
from polyplug_loaders_dotnet import DotNetLoader

loader = DotNetLoader()
# Load plugins written in C#, F#, or other .NET languages
```

## Description

This loader handles plugins written in .NET languages (C#, F#, VB.NET, etc.), bridging the polyplug runtime with the .NET CLR.
